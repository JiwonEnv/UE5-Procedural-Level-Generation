# UE5-Procedural-Level-Generation

Unreal Engine 5 모듈 조립형 절차적 맵 생성 기술 템플릿 · 시드 기반 방 조립, 런타임 내비메시, 멀티플레이 동기화, 재사용 플러그인

> **진행 중 · 현재 STEP 0 (연구·설계)**
> 아직 UE5 프로젝트와 코드는 없습니다. 이 저장소는 단계별 구현 기록을 위해 먼저 만들었습니다.

## 목적

절차적 맵 생성 시스템을 직접 구현하고 검증하는 기술 템플릿 프로젝트입니다.
각 기능의 사용 목적과 적용 시점, 관리 방법을 함께 기록해 이후 환경 프로젝트에서 재사용할 기술 기반을 만듭니다.

## 범위

미리 만든 방 모듈을 시드(seed)에 따라 매번 다른 순서와 연결로 이어 붙여 맵을 만드는 **모듈 조립형** 방식입니다. 벽과 바닥까지 생성하는 완전 생성형은 다루지 않습니다.

| STEP | 내용 |
|---|---|
| 0 | 준비: 개념, 사례, UE5 도구 조사 |
| 1 | 프로젝트 관리: 저장소, Git LFS, 폴더 구조, 커밋 규칙 |
| 2 | 모듈 규격: 그리드, 문 소켓, 층 높이, 피벗, 경계 |
| 3 | 방 모듈 제작: Level Instance, 표식 액터, 모듈 카탈로그 |
| 4 | 생성 알고리즘: 시드, 방 연결, 겹침 검사 |
| 5 | 런타임 내비메시와 AI 연결 |
| 6 | 멀티플레이 시드 동기화 |
| 7 | 콘텐츠 배치: 스폰 포인트 풀, 잠긴 문 |
| 8 | 디버그와 검증: 시드 고정, 시각화, 자동 생성 검사 |
| 9 | 다른 프로젝트 적용: 플러그인화 |

## 폴더 구조 (계획)

| 폴더 | 내용 |
|---|---|
| `Plugins/ProcLevelGen` | 다른 프로젝트에 가져갈 생성기 본체 (C++ + 데이터) |
| `Content/Rooms` | 테스트용 방 모듈 (시작 · 통로 · 방 · 끝) |
| `Content/Maps` | 테스트 맵 |
| `Docs` | 모듈 규격과 단계별 기록 |
