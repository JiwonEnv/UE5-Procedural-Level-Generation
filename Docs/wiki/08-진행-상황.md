## 제작 단계

| STEP | 내용 | 상태 | 된 것 | 남은 것 |
|:---:|---|:---:|---|---|
| 1 | 모듈 규격 | ✅ | 피벗 · 그리드 · 벽 · 문 소켓 · 스폰 포인트 규격, 규격 위반 경고 | 층 이동(계단) 규격 |
| 2 | 방 모듈 | 🚧 | 그레이박스 샘플 키트 8종 (고정 방 3 + 일반 방 틀 2 + 통로 3) | Level Instance 로 실제 방 내용물, 재질 테마 (지금은 색만) |
| 3 | 시드와 규칙 | ✅ | 시드 · `RoomCount` · `CorridorChance` · 범위, 시드 고정 옵션 | |
| 4 | 출구에 방 붙이기 | ✅ | 빈 문 선택, 소켓 매칭, 고리 연결, 가중치 | |
| 5 | 겹침 검사 | ✅ | 경계 박스 검사, 파생 시드 16회 + 서버 대체 시드 재시도, 실패 처리 | |
| 6 | 흐름 고정 | ✅ | 시작 · 허브 · 끝 고정, 끝 방은 가장 먼 문(BFS), 막다른 통로 정리, 테마 분산 | 실제 걷는 거리(cm) 기준 |
| 7 | 콘텐츠 배치 | 🚧 | 태그 스폰 포인트, 소품 상자, 시드 기반 콘텐츠 난수 | 잠긴 문 · 열쇠 (열쇠는 문보다 시작 쪽) |
| 8 | 길찾기 · 동기화 | ✅ | 시드 복제, 런타임 내비메시 갱신, `IsNavigationReady`, 서버 · 클라이언트 같은 맵 확인 | |
| 9 | 자동 검증 | 🚧 | 생성 직후 검증, 에디터 200시드 검사, `-plgselftest`, 실패 키트 | 커맨드릿 버전, 소켓 · 연결 그래프 시각화 |
