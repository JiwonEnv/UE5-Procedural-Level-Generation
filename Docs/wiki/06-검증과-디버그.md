# 🧪 검증과 디버그

절차적 맵은 조합마다 깨질 수 있어서, **사람이 몇 판 돌려 보는 것으로는 부족합니다.** 세 겹으로 검사합니다.

| 층 | 언제 | 무엇을 |
|---|---|---|
| ① 생성 직후 검증 | 매 생성마다 (게임 안) | 규칙 위반이 있으면 짓지 않음 |
| ② 에디터 200시드 검사 | 모듈 · 규칙을 바꿀 때 | 시드 1~200 을 한 번에 |
| ③ 게임 실행 자가 검사 | 빌드 확인할 때 | 실제 게임에서 바닥 · 내비 · 스크린샷 |

## ① 생성 직후 검증 (`PLG::ValidateLayout`)

생성기는 조립 결과를 짓기 전에 따로 검사합니다. 통과한 레이아웃만 짓습니다.

| 검사 | 실패 예 |
|---|---|
| 역할별 개수 | 시작 · 허브 · 끝이 1개가 아님, 일반 방이 `RoomCount` 와 다름 |
| 겹침 | 두 방의 바닥 면적이 겹침 |
| 양방향 문 연결 | A → B 는 이어졌는데 B → A 가 없음, 두 문의 위치가 다름 |
| 도달 가능 | 시작에서 갈 수 없는 방이 있음 |
| 막다른 통로 | 연결이 하나뿐인 통로가 남음 |
| Depth | 저장된 깊이가 문 연결 수 기준 최단거리와 다름 |

## ② 에디터 200시드 검사

```
UnrealEditor-Cmd.exe <프로젝트>.uproject -ExecutePythonScript="Tools/ue/test_proc_level.py"
```

시드마다 ①의 항목에 더해 **앞쪽 방 테마 중복 없음, 그레이박스 생성, 같은 시드를 다시 지으면 완전히 같은 레이아웃**까지 봅니다. 아무것도 저장하지 않고 `[PLGTest] PASS/FAIL` 줄만 남깁니다.

최근 결과: `[PLGTest] PASS 200/200 seeds` (약 17초).

## ③ 게임 실행 자가 검사 (`-plgselftest`)

```
UnrealEditor.exe <프로젝트>.uproject /Game/Maps/Lvl_ProcGen?listen -game -plgselftest -plgseed=535117761
```

실제 게임을 띄워 검사하고 스스로 종료합니다. **실패하면 종료 코드 1** 이라 자동화에 바로 쓸 수 있습니다.

```
[PLGSelfTest] PASS generation succeeded: seed 535117761, 9 modules, layout hash e94bc661
[PLGSelfTest] PASS layout passes ValidateLayout
[PLGSelfTest] PASS 113 graybox boxes built
[PLGSelfTest] PASS player stands on the generated floor (z 57, vz 0)
[PLGSelfTest] PASS navigation reaches 8/8 modules from the start
```

검사가 끝나면 위에서 본 화면과 플레이어 시점 스크린샷을 남깁니다. [갤러리](01-생성-갤러리)의 사진이 이렇게 찍혔습니다.

## 일부러 실패시키기

실패 처리가 정말 동작하는지도 검사해야 합니다.

| 명령줄 | 하는 일 | 기대 결과 |
|---|---|---|
| `-plgtestkit=empty` | 빈 키트로 생성 | 아무것도 안 짓고 `OnGenerated(…, false)` |
| `-plgtestkit=impossible` | 범위 1,000cm 로 배치 불가능하게 | 위와 같음 |

꿈 수거반에서는 이때 라운드가 시작되지 않는지(타이머 · 몬스터 · 골동품 없음)까지 확인합니다.

## 개발용 명령줄 정리

| 명령줄 | 뜻 |
|---|---|
| `-plgseed=N` | 시드 고정 |
| `-plgtestkit=empty\|impossible` | 일부러 실패 |
| `-plgselftest` | 자가 검사 후 종료 (실패 시 종료 코드 1) |
| `-LogCmds="LogProcLevelGen Verbose"` | 모듈별 위치까지 로그 |

## 디버그 팁

- **버그 리포트에는 시드를 남깁니다.** 로그의 `seed N: M modules` 를 `-plgseed=N` 으로 넣으면 같은 맵이 나옵니다.
- 같은 시드인데 맵이 다르면 레이아웃 해시(`layout hash`)를 비교합니다. 서버와 클라이언트 해시가 다르면 조립 안에서 시드 밖 난수를 쓴 것입니다.
- 모듈 이름 라벨은 `bShowLabels` 로 켭니다.
