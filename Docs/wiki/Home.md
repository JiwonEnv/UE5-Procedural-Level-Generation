# 🧩 절차적 맵 생성 가이드

Unreal Engine 5.8 에서 **미리 만든 방 모듈을 시드에 따라 이어 붙이는** 모듈 조립형 맵 생성기 안내서입니다.
**결과 → 선택 기준 → 사용법 → 원리 → 기록** 순서로 정리했습니다.

## 👋 처음이라면 여기부터

| 순서 | 페이지 | 읽는 시간 | 이런 분께 |
|:---:|---|:---:|---|
| 1 | [🗺 생성 갤러리](01-생성-갤러리) | 1분 | 어떤 맵이 나오는지 먼저 보고 싶다 |
| 2 | [🤔 언제 쓰나](02-언제-쓰나) | 5분 | 내 프로젝트에 절차적 맵이 맞는지 판단하고 싶다 |
| 3 | [🚀 바로 써보기](03-바로-써보기) | 10분 | 플러그인을 넣고 바로 맵을 뽑아 보고 싶다 |
| 4 | [🛠 만드는 방법](04-만드는-방법) | 15분 | 생성기가 어떤 순서로 만들어지는지 궁금하다 |
| 5 | [📐 모듈 규격](05-모듈-규격) | 필요할 때 | 새 방 모듈을 규격에 맞게 만들고 싶다 |
| 6 | [🧪 검증과 디버그](06-검증과-디버그) | 10분 | 수백 개 시드를 자동으로 검사하는 방법 |
| 7 | [🩹 문제 해결](07-문제-해결) | 필요할 때 | 맵이 안 나오거나 몬스터가 안 움직인다 |
| 8 | [📍 진행 상황](08-진행-상황) | 2분 | 어디까지 구현됐고 무엇이 남았나 |
| 9 | [🗓 변경 이력](09-변경-이력) | 3분 | 날짜별로 무엇이 바뀌었나 |

## ⚡ 한눈에 보는 흐름

```mermaid
flowchart LR
    A[모듈 규격] --> B[방 모듈 키트]
    B --> C[시드 · 규칙]
    C --> D[빈 문에 방 붙이기]
    D --> E[겹침 검사]
    E --> F[시작 · 허브 · 끝 고정]
    F --> G[콘텐츠 배치]
    G --> H[내비메시 · 시드 동기화]
    H --> I[자동 검증]
```

## 📌 꼭 알아둘 3가지

1. **같은 시드는 언제나 같은 맵입니다.** 멀티플레이에서는 서버가 시드 숫자 하나만 보내고, 모두가 같은 맵을 직접 짓습니다.
2. **방은 손으로, 연결은 규칙으로.** 방 안 장식은 자유지만 피벗 · 그리드 · 문 소켓은 [모듈 규격](05-모듈-규격)을 따라야 어떤 순서로 붙여도 맞물립니다.
3. **검증을 통과한 맵만 짓습니다.** 실패하면 다른 시드로 다시 시도하고, 모두 실패하면 아무것도 짓지 않고 `OnGenerated(생성기, false)`를 알립니다.
