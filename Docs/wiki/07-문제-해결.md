# 🩹 문제 해결

## 증상별 원인과 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 플레이하면 아무것도 안 지어진다 | 모든 시드가 검증에 실패 (`OnGenerated(…, false)`) | 로그 `LogProcLevelGen` 의 실패 이유를 봅니다. 키트에 시작 · 허브 · 끝이 하나씩 있는지, `RoomCount` 가 키트로 채울 수 있는 수인지, `MaxHalfExtent` 가 너무 작지 않은지 확인 |
| 몬스터가 안 움직인다 | 맵에 내비메시 데이터(`RecastNavMesh`)가 없음 | 헤드리스 에디터로 맵을 만들면 `RecastNavMesh` 가 생기지 않습니다. 맵에 Nav Mesh Bounds Volume 을 두고 내비 데이터를 만들어 저장 |
| 일부 방에서만 몬스터가 못 간다 | Nav Mesh Bounds Volume 이 맵 일부만 덮음 | 볼륨을 생성기 기준 `MaxHalfExtent`(기본 ±5,000cm) 전체로 |
| 내비 준비가 끝나지 않는다 | `IsNavigationReady` 가 계속 거짓 | 거짓일 때 함께 나오는 이유 문자열(데이터 없음 · 빌드 대기 · 내비 없는 모듈)을 확인. 프로젝트 설정의 Runtime Generation 이 Dynamic 인지 확인 |
| 서버와 클라이언트 맵이 다르다 | 조립 코드에서 시드 밖 난수 사용, 또는 키트 설정이 다름 | 레이아웃 해시를 비교하고, 조립 안 무작위 선택이 모두 시드의 `FRandomStream` 을 쓰는지 확인 |
| 방이 붙지 않고 벽만 남는다 | 문 소켓이 규격과 다름 (위치 · 방향 · 폭) | [모듈 규격](05-모듈-규격) 4장. 위치가 같고, 마주 보고, 폭이 같아야 연결됩니다 |
| 규격 경고가 뜬다 | 스폰 포인트 · 소품이 풋프린트 밖, 크기가 100cm 배수가 아님 등 | 경고에 나온 모듈의 값을 규격에 맞게 수정 |
| 방 사이 벽이 두 겹 / 틈이 생긴다 | 모듈이 벽을 풋프린트 바깥으로 지음 | 벽은 풋프린트 **안쪽으로 절반(10cm)** 만. 두 모듈이 맞닿아 20cm 가 됩니다 |
| 미리보기가 레벨에 남지 않는다 | 의도된 동작 | 미리보기는 저장되지 않습니다. 플레이할 때 다시 짓습니다 |
| 특정 맵을 다시 보고 싶다 | 매번 새 시드 | 로그의 시드를 `Seed` 에 넣고 `bNewSeedEachRun` 끄기, 또는 `-plgseed=N` |

## 그래도 안 될 때

1. `-LogCmds="LogProcLevelGen Verbose"` 로 모듈별 위치를 찍어 봅니다.
2. `-plgselftest` 로 어느 검사에서 실패하는지 봅니다. ([검증과 디버그](06-검증과-디버그))
3. 같은 시드로 에디터 **Preview** 를 눌러 위에서 확인합니다.
