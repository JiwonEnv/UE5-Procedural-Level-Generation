# 🚀 바로 써보기

원리는 몰라도 됩니다. 플러그인을 넣고, 생성기를 놓고, 시드를 돌리면 됩니다.

## 1. 플러그인 넣기

1. 이 저장소의 `Plugins/ProcLevelGen` 폴더를 내 프로젝트의 `Plugins/` 에 복사합니다.
2. `.uproject` 를 열면 "다시 빌드할까요?" 창이 뜹니다. **예**를 누르면 플러그인이 같이 빌드됩니다. (C++ 프로젝트여야 합니다)

## 2. 생성기 놓기

1. 레벨에 `PLGGenerator` 액터를 놓습니다. 이 위치가 **시작 방의 중심(원점)** 이 됩니다.
2. 생성된 맵 전체를 덮도록 **Nav Mesh Bounds Volume** 을 놓습니다. 기본 범위는 생성기에서 ±5,000cm 입니다.
3. 플레이어 시작 지점은 시작 방(1000 × 1000cm) 안에 둡니다.

> 새로 놓은 생성기의 키트(`Modules`)에는 샘플 키트 8종이 이미 들어 있습니다. 바로 시험하기에 충분합니다.

## 3. 에디터에서 미리 보기

Details 패널 **Generation** 항목의 버튼:

| 버튼 | 하는 일 |
|---|---|
| **Preview** | 지금 `Seed` 로 맵을 짓습니다 |
| **Preview New Seed** | 새 시드를 골라 짓습니다 |
| **Clear Preview** | 미리보기를 지웁니다 |

미리보기는 레벨에 저장되지 않습니다.

## 4. 플레이

- 플레이하면 서버가 새 시드를 골라 복제하고, 모든 컴퓨터가 같은 맵을 짓습니다.
- 출력 로그에 `LogProcLevelGen: ... seed N: M modules` 가 찍힙니다.
- **특정 맵을 다시 보려면** 로그의 시드를 `Seed` 에 넣고 `bNewSeedEachRun` 을 끕니다. 또는 명령줄 `-plgseed=N`.

```cpp
    }
}

```

## 주요 설정

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `Seed` | 1 | 시드. 복제됩니다 |
| `bNewSeedEachRun` | 켬 | 플레이할 때마다 새 시드 |
| `RoomCount` | 4 | 일반 방 개수 (통로 제외) |
| `CorridorChance` | 0.45 | 빈 문에 통로를 붙일 확률 |
| `MaxSeedRetries` | 3 | 실패 시 서버가 다른 시드로 다시 시도하는 횟수 |
| `MaxHalfExtent` | 5000 | 생성기에서 이 거리(cm) 밖으로는 방을 놓지 않음 |
| `bShowLabels` | 켬 | 모듈 이름 라벨 표시 |
