## 2026-11-09 · 문서

- README 를 쇼케이스 형식으로 바꾸고 GitHub Wiki 를 만들었습니다.
- STEP 번호를 노션 포트폴리오의 "제작 방법" 9단계로 통일했습니다.

## 2026-11-04 · 결과 검증과 실패 처리 (반영 예정)

- 생성 결과를 `PLG::ValidateLayout` 으로 따로 검사하고, 통과한 레이아웃만 짓습니다.
- 서버가 실패하면 다른 시드로 `MaxSeedRetries` 번 더 시도합니다. 모두 실패하면 `OnGenerated(생성기, false)`.
- 끝 방을 문 연결 수 기준 가장 먼 문(BFS, 고리 반영)에 붙이고, 모든 모듈의 `Depth` 를 다시 계산합니다.
- `IsNavigationReady` 추가, 생성 뒤 레이아웃 범위를 내비 dirty 영역으로 알림.
- 개발용 명령줄 `-plgseed`, `-plgtestkit=empty|impossible`.

## 2026-11-04 · 스폰 포인트와 소품

- 모듈에 태그 스폰 포인트(`Item` · `HideSmall` · `HideLarge` · `Guard`)와 소품 상자를 추가했습니다.
- `GetSpawnSlots(태그)`, `MakeContentStream()` 추가.
- 꿈 수거반에서 생성된 맵에 골동품 · 옷장 · 몬스터를 배치하기 시작했습니다.

## 2026-11-03 · 생성기 첫 버전과 검사
